# Workflow — Generate Style Options

Use when the user wants several genuinely different editing directions before defining a pattern.

Generate 2–4 alternatives that differ in mechanisms, not only names:
- pace;
- silence/filler policy;
- caption density;
- reframing/punch-in logic;
- motion/B-roll intensity;
- audio treatment;
- render engine complexity.

State tradeoffs and what each option would require. Do not rank the options unless the user provides a non-political domain-specific criterion and asks for an evaluation.
