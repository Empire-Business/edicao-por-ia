# Workflow — Learn From Feedback or Results

Learning from an explicit user preference does NOT require audience metrics.
Run `FORMAT_MEMORY.md` during each relevant turn; do not wait until publication.

Separate three outputs:
1. User facts/preferences/corrections: saved immediately to the right format's scoped memory.
2. Specific approvals/rejections: preserve the artifact and version; approval is a reference,
   not a universal pattern and not a measured winner. Unknown target/cause stays a candidate.
3. Actual results: record metric definition, period, source, comparison (null if absent),
   edit/pattern version, changes and limitations. A reported result is not proof of causation.

Historical `memory/winners`, `failures`, `decisions` remain readable sources only when explicitly
assigned to the active format. Do not mix or auto-import those old global folders.
No new format data goes there. There is no automatic promotion to winner in the v1.4 tool.
A preference about preserving rhetorical pauses becomes source-specific protected ranges on the
next edit, not reuse of timestamps from the previous recording.
