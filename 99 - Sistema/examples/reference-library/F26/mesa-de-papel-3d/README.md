# F26 — Mesa de Papel 3D

Formato criado pelo autor em 28/11/2026 a partir de um criativo real do lote do Cortez (E123 V2), publicado como modelo a pedido dele. Cena clara de mesa de papel em 3D, com sombras suaves e plano-sequência: relógio, calendário, cópias impressas e agenda viram objetos que contam a fala.

`reference.mp4` é uma cópia leve da prévia; o original fica na instalação do autor. As imagens são quadros reais desse vídeo e as provas mostradas são vídeos do próprio autor editados pelo Cortez.

Pessoas, nomes, assunto, provas, cores e fontes do exemplo não são padrões: a aparência vem da ID escolhida. O código-base da composição está em `motion/templates/mesa-de-papel-3d`. A receita é rascunho e ainda não foi testada numa edição de outro tema.
