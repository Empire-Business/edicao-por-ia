# F48 — Pilha de Versões

Formato criado pelo autor em 28/11/2026 a partir de um criativo real do lote do Cortez (E144 V1), publicado como modelo a pedido dele. O mesmo vídeo num suporte 3D: a cada pedido dito, uma mudança visível acontece (cena, legenda, música) e uma nova placa de versão entra na pilha.

`reference.mp4` é uma cópia leve da prévia; o original fica na instalação do autor. As imagens são quadros reais desse vídeo e as provas mostradas são vídeos do próprio autor editados pelo Cortez.

Pessoas, nomes, assunto, provas, cores e fontes do exemplo não são padrões: a aparência vem da ID escolhida. O código-base da composição está em `motion/templates/pilha-de-versoes`. A receita é rascunho e ainda não foi testada numa edição de outro tema.
