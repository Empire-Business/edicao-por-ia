# F45 — Estúdio de Marca

Formato criado pelo autor em 28/11/2026 a partir de um criativo real do lote do Cortez (E141 V1), publicado como modelo a pedido dele. Um kit de marca em 3D — leque de cores, tipos de metal, placas de legenda — monta a identidade visual, e o mesmo vídeo troca de roupa ao vivo em várias identidades.

`reference.mp4` é uma cópia leve da prévia; o original fica na instalação do autor. As imagens são quadros reais desse vídeo e as provas mostradas são vídeos do próprio autor editados pelo Cortez.

Pessoas, nomes, assunto, provas, cores e fontes do exemplo não são padrões: a aparência vem da ID escolhida. O código-base da composição está em `motion/templates/estudio-de-marca`. A receita é rascunho e ainda não foi testada numa edição de outro tema.
