# F22 · Anúncio com motion — referência

Exemplo real aprovado pelo autor: anúncio vertical de 68 s de um produto digital, editado com o kit `studio/ad-motion`.

- `reference.mp4`: versão final (cópia otimizada H.264 1080x1920).
- Quadros-chave: `gancho-galeria.jpg`, `revelacao-timeline.jpg`, `app-assistente.jpg`, `modelos-mostrador.jpg`, `resultado-identidade.jpg`, `apresentador-titulo.jpg`.
- `analysis.json`: mecânica, passos, cuidados, observações das rodadas de revisão e limites.

O nome do produto aparece porque é o assunto do anúncio. Pessoa, produto, cores e fontes do exemplo não viram padrão do formato.
