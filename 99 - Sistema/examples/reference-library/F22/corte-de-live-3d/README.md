# F22 — Corte de Live 3D

Formato criado pelo autor em 27/11/2026 a partir de uma edição real aprovada por ele: um corte de live (entrevista com um cliente) virou criativo 9:16 para anúncio, com a fala real conduzindo e cenas 3D de prova (three.js) entrando quando a fala cita o resultado, e chamada escrita "Saiba mais" no fim.

`reference.mp4` é uma cópia H.264 da prévia aprovada (E119 V1); o original fica na instalação do autor. As imagens são quadros reais desse vídeo. As provas mostradas são vídeos do próprio autor editados pelo Cortez.

Pessoas, nomes, assunto, provas, o dourado e as fontes do exemplo não são padrões: a aparência vem da ID escolhida. O código-base da composição está em `motion/templates/corte-de-live-3d`. A receita é rascunho e ainda não foi testada numa edição de outro tema.
