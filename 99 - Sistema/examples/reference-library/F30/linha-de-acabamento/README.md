# F30 — Linha de Acabamento

Formato criado pelo autor em 28/11/2026 a partir de um criativo real do lote do Cortez (E128 V1), publicado como modelo a pedido dele. O material bruto real desfila numa esteira 3D e passa por estações; a cada etapa narrada ele muda de estado até sair como vídeo pronto, aprovado com um toque.

`reference.mp4` é uma cópia leve da prévia; o original fica na instalação do autor. As imagens são quadros reais desse vídeo e as provas mostradas são vídeos do próprio autor editados pelo Cortez.

Pessoas, nomes, assunto, provas, cores e fontes do exemplo não são padrões: a aparência vem da ID escolhida. O código-base da composição está em `motion/templates/linha-de-acabamento`. A receita é rascunho e ainda não foi testada numa edição de outro tema.
