# F42 — Túnel da Pasta

Formato criado pelo autor em 28/11/2026 a partir de um criativo real do lote do Cortez (E138 V1), publicado como modelo a pedido dele. O material entra numa pasta 3D, a câmera mergulha num túnel por dentro da máquina onde cada etapa transforma o clipe, e o resultado sai pronto pela outra pasta.

`reference.mp4` é uma cópia leve da prévia; o original fica na instalação do autor. As imagens são quadros reais desse vídeo e as provas mostradas são vídeos do próprio autor editados pelo Cortez.

Pessoas, nomes, assunto, provas, cores e fontes do exemplo não são padrões: a aparência vem da ID escolhida. O código-base da composição está em `motion/templates/tunel-da-pasta`. A receita é rascunho e ainda não foi testada numa edição de outro tema.
