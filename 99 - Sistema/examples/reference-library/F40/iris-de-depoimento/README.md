# F40 — Íris de Depoimento

Formato criado pelo autor em 28/11/2026 a partir de um criativo real do lote do Cortez (E135 V2), publicado como modelo a pedido dele. Um narrador de IA aparece como íris dourada em 3D que pulsa com a voz; ao dizer "ouça quem usa", a íris abre e revela o depoimento real de uma pessoa.

`reference.mp4` é uma cópia leve da prévia; o original fica na instalação do autor. As imagens são quadros reais desse vídeo e as provas mostradas são vídeos do próprio autor editados pelo Cortez.

Pessoas, nomes, assunto, provas, cores e fontes do exemplo não são padrões: a aparência vem da ID escolhida. O código-base da composição está em `motion/templates/iris-de-depoimento`. A receita é rascunho e ainda não foi testada numa edição de outro tema.
