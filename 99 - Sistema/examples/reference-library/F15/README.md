# F15 — Dois Lados

A pessoa classifica opções em duas colunas, e cada item ocupa o lado indicado pela fala.

Receita atual: `patterns/f15-v1.yaml`. Cores e fontes vêm da ID escolhida. Nenhum logotipo, nome fixo de empresa ou assinatura de marca entra automaticamente. As referências preservam sua aparência histórica; pessoa e assunto não são escolhas para outra edição.

## Guia atual do mecanismo

Duas áreas com rótulos organizam a comparação. Cada item aparece quando é citado e vai para o lado escolhido, permanecendo até o quadro final.

### O que enviar

Vídeo da pessoa, os dois critérios de classificação e itens ou imagens relacionados à fala. Escolher a ID visual e a proporção.

### Sequência

1. Conferir os dois critérios e a classificação de cada item na fala.
2. Criar duas áreas legíveis sem cobrir rosto, mãos ou legenda.
3. Apresentar cada item no momento correspondente e posicioná-lo no lado correto.
4. Manter os itens já classificados para formar a comparação final.
5. Revisar sentido, posição, leitura e sincronia antes da entrega.

### Cuidados

Não inverter o sentido da classificação, fabricar recomendações, fixar verde/vermelho como parte do formato ou transformar um exemplo de finanças em conselho para outro vídeo.
