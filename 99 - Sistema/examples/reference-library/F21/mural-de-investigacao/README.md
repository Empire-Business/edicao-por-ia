# F21 — Mural de investigação

Formato criado pelo autor em 21/10/2026. Uma investigação contada num mural de cortiça: evidências reais entram uma por vez, com atos, contador de itens, carimbos só quando a fala diz, status jurídico em cartões próprios, áudio original com forma de onda e panorama final ligado por fios. Legenda karaokê no terço inferior.

`reference.mp4` é o demo "O roubo da Mona Lisa (1911)", cópia H.264 720x1280, feito com `tools/mural_board.py` e a ID09 Mural escuro. As fotos são de época e em domínio público (Wikimedia Commons), com crédito na polaroide; a narração é própria, gerada localmente. As imagens `.jpg` são quadros reais desse vídeo.

Caso, pessoas, fotos e cores do demo não são padrões: o caso e as fotos vêm do trabalho e a aparência vem da ID escolhida. A receita é rascunho.
