# F31 — Bastidor em Wireframe

Formato criado pelo autor em 28/11/2026 a partir de um criativo real do lote do Cortez (E129 V1), publicado como modelo a pedido dele. Tom de confissão: a narração revela um segredo e o próprio cenário vira wireframe, mostrando os bastidores 3D, até renderizar o resultado final.

`reference.mp4` é uma cópia leve da prévia; o original fica na instalação do autor. As imagens são quadros reais desse vídeo e as provas mostradas são vídeos do próprio autor editados pelo Cortez.

Pessoas, nomes, assunto, provas, cores e fontes do exemplo não são padrões: a aparência vem da ID escolhida. O código-base da composição está em `motion/templates/bastidor-em-wireframe`. A receita é rascunho e ainda não foi testada numa edição de outro tema.
