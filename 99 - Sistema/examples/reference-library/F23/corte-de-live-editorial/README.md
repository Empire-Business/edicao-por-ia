# F23 — Corte de Live Editorial

Formato criado pelo autor em 28/11/2026 a partir de um criativo real do lote do Cortez (E118 V2), publicado como modelo a pedido dele. Trecho de entrevista ou live em 9:16 com cara de revista: pergunta e resposta em cartões, títulos editoriais curtos e a prova real num celular 3D sóbrio, com chamada escrita no fim.

`reference.mp4` é uma cópia leve da prévia; o original fica na instalação do autor. As imagens são quadros reais desse vídeo e as provas mostradas são vídeos do próprio autor editados pelo Cortez.

Pessoas, nomes, assunto, provas, cores e fontes do exemplo não são padrões: a aparência vem da ID escolhida. O código-base da composição está em `motion/templates/corte-de-live-editorial`. A receita é rascunho e ainda não foi testada numa edição de outro tema.
