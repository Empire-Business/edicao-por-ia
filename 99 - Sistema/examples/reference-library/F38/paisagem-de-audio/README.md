# F38 — Paisagem de Áudio

Formato criado pelo autor em 28/11/2026 a partir de um criativo real do lote do Cortez (E126 V2), publicado como modelo a pedido dele. A voz de um depoimento vira uma paisagem 3D de barras com uma luz que corre junto com a fala; palavras-chave sobem em 3D e as provas aparecem; fecha numa rua de vídeos.

`reference.mp4` é uma cópia leve da prévia; o original fica na instalação do autor. As imagens são quadros reais desse vídeo e as provas mostradas são vídeos do próprio autor editados pelo Cortez.

Pessoas, nomes, assunto, provas, cores e fontes do exemplo não são padrões: a aparência vem da ID escolhida. O código-base da composição está em `motion/templates/paisagem-de-audio`. A receita é rascunho e ainda não foi testada numa edição de outro tema.
