# F19 — Print Repost

Formato criado pelo autor em 20/10/2026. Um vídeo pronto é repostado como print de post: foto, nome e @ no alto, frase de gancho com destaque e, embaixo, uma foto chamativa parada ao lado do vídeo. Trocar a foto ou a frase gera uma variação nova para testar reels.

`reference.mp4` é uma cópia H.264 do exemplo enviado pelo autor (o original HEVC fica na instalação dele). As imagens são quadros reais desse vídeo. O logotipo do Instagram que passeia pela tela e o cartão final com o @ vêm do download do Instagram e não fazem parte do formato.

Pessoa, nome, @, foto, assunto, vermelho e fonte do exemplo não são padrões: o cabeçalho vem do trabalho e a aparência vem da ID escolhida. A receita é rascunho e ainda não foi testada numa edição nova.
