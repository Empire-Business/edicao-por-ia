# F02 — Talking Head

Referência real fornecida pelo autor via o link do ZIP F06 - Talking head 1.zip. O código F06 existente permanece Diagramas; F02 é uma nova geração, com UID e memória próprios.

O guia original do ZIP repetia Diagramas por engano. A receita e o guia atuais foram derivados da inspeção de 27 frames do vídeo real de 185,37s: faixa de gancho na abertura, apresentador durante o corpo, B-roll, split com emenda suave, manchete destacada e cartões.

reference.mp4 contém o vídeo completo em 1080x1920, com compressão para caber no GitHub; a faixa AAC foi copiada, sem remix. O original de 166.157.493 bytes permanece imutável no arquivo local do autor, e sua origem/hash constam em analysis.json. As imagens são frames reais desse exemplo. Não são ilustrações nem uma edição produzida pela fábrica.

Cor, fonte, rosto, temas, marcas e falas do exemplo não são defaults. A receita é draft até aplicação/piloto real; esta análise não certifica uma nova execução artística.
