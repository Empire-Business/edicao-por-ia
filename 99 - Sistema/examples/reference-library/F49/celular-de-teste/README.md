# F49 — Celular de Teste

Formato criado pelo autor em 28/11/2026 a partir de um criativo real do lote do Cortez (E145 V1), publicado como modelo a pedido dele. Um celular 3D mostra a galeria com o vídeo parado; o vídeo sai da tela, vai para a pasta, o tempo corre e ele volta pronto, com etiquetas de cada coisa feita.

`reference.mp4` é uma cópia leve da prévia; o original fica na instalação do autor. As imagens são quadros reais desse vídeo e as provas mostradas são vídeos do próprio autor editados pelo Cortez.

Pessoas, nomes, assunto, provas, cores e fontes do exemplo não são padrões: a aparência vem da ID escolhida. O código-base da composição está em `motion/templates/celular-de-teste`. A receita é rascunho e ainda não foi testada numa edição de outro tema.
