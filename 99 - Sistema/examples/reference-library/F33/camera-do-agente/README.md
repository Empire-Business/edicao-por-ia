# F33 — Câmera do Agente

Formato criado pelo autor em 28/11/2026 a partir de um criativo real do lote do Cortez (E132 V1), publicado como modelo a pedido dele. A câmera é o próprio software trabalhando: navega pelas telas reais, tira print, grava a tela e monta o resultado, com uma lista que vai se marcando no alto.

`reference.mp4` é uma cópia leve da prévia; o original fica na instalação do autor. As imagens são quadros reais desse vídeo e as provas mostradas são vídeos do próprio autor editados pelo Cortez.

Pessoas, nomes, assunto, provas, cores e fontes do exemplo não são padrões: a aparência vem da ID escolhida. O código-base da composição está em `motion/templates/camera-do-agente`. A receita é rascunho e ainda não foi testada numa edição de outro tema.
