# F47 — Linha do Tempo que se Organiza

Formato criado pelo autor em 28/11/2026 a partir de um criativo real do lote do Cortez (E143 V1), publicado como modelo a pedido dele. Uma linha do tempo de edição lotada, à noite, com o contador de horas subindo; no momento da virada, centenas de clipes decolam e se organizam sozinhos no vídeo pronto.

`reference.mp4` é uma cópia leve da prévia; o original fica na instalação do autor. As imagens são quadros reais desse vídeo e as provas mostradas são vídeos do próprio autor editados pelo Cortez.

Pessoas, nomes, assunto, provas, cores e fontes do exemplo não são padrões: a aparência vem da ID escolhida. O código-base da composição está em `motion/templates/linha-do-tempo-que-se-organiza`. A receita é rascunho e ainda não foi testada numa edição de outro tema.
