# F13 — Dados Dark: referência analisada

Referência: condzxyz, 30,06 s, 1080x1920, H.264, 30 fps, com áudio.
A cópia local foi verificada por SHA-256. Só este vídeo foi usado; greco_dev foi excluído do pedido pelo usuário.

## Mecanismo observado

- Abertura: pergunta em título, mapa e dois valores comparáveis.
- Aproximadamente 3 s: pontos/partículas reorganizam o conjunto geográfico.
- Aproximadamente 6–11 s: grades de pontos e contadores com o mesmo universo de comparação.
- Aproximadamente 14 s: aproximação de local específico e cartão com unidades/valores.
- Aproximadamente 19–23 s: números grandes e continuidade da linha narrativa.
- Aproximadamente 27 s: fechamento visual retoma mapa e síntese.

## Transferível

Narração sem apresentador, dados como objetos visuais, mapas com foco geográfico, grades de quantidade,
comparações e destaque sequencial. Títulos são estruturais; legendas não devem competir com os valores.

## Não transferível

Partido, posição política, pessoas retratadas, alegações, dados eleitorais, CTA e marca de autoria.
Os números do exemplo não foram verificados nesta tarefa. A paleta e as fontes pertencem à ID visual escolhida.
“Dark” no nome foi pedido pelo usuário e indica aqui um formato sem apresentador, não uma ID visual automática.
