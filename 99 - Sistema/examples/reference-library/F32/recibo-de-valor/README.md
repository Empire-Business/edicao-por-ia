# F32 — Recibo de Valor

Formato criado pelo autor em 28/11/2026 a partir de um criativo real do lote do Cortez (E130 V1), publicado como modelo a pedido dele. Comparação de valor em cenário escuro e luxuoso: uma etiqueta de preço que vira na palavra-chave, um recibo que imprime o que o produto entrega e pilhas do custo alternativo.

`reference.mp4` é uma cópia leve da prévia; o original fica na instalação do autor. As imagens são quadros reais desse vídeo e as provas mostradas são vídeos do próprio autor editados pelo Cortez.

Pessoas, nomes, assunto, provas, cores e fontes do exemplo não são padrões: a aparência vem da ID escolhida. O código-base da composição está em `motion/templates/recibo-de-valor`. A receita é rascunho e ainda não foi testada numa edição de outro tema.
