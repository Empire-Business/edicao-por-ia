# F36 — Interface em 3D

Formato criado pelo autor em 28/11/2026 a partir de um criativo real do lote do Cortez (E136 V1), publicado como modelo a pedido dele. A interface real do produto ganha volume: cartões sobem da página, botões afundam no clique e o fluxo de uso vira uma demonstração 3D clara, do primeiro clique ao resultado.

`reference.mp4` é uma cópia leve da prévia; o original fica na instalação do autor. As imagens são quadros reais desse vídeo e as provas mostradas são vídeos do próprio autor editados pelo Cortez.

Pessoas, nomes, assunto, provas, cores e fontes do exemplo não são padrões: a aparência vem da ID escolhida. O código-base da composição está em `motion/templates/interface-em-3d`. A receita é rascunho e ainda não foi testada numa edição de outro tema.
