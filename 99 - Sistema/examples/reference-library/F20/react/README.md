# F20 — React

Formato criado pelo autor em 21/10/2026. O apresentador reage a um vídeo: gancho em tela dividida com o momento mais chamativo do vídeo em cima, flare de luz para o react (vídeo-fonte em cima, apresentador assistindo no celular embaixo, legenda amarela das falas do vídeo), outro flare para o comentário em tela cheia — fala rápida e sem pausas, zoom alternado nos cortes e splits curtos com B-roll específico, cenas de filmes famosos ou o próprio vídeo-fonte quando citado.

`reference.mp4` é uma cópia H.264 720x1280 do exemplo enviado pelo autor, publicado com autorização dele (o original fica na instalação dele). As imagens são quadros reais desse vídeo. O flare de transição é reproduzido por `tools/flare_transition.py`.

Pessoa, assunto, vídeo reagido, cores e fonte do exemplo não são padrões: a pessoa e os vídeos vêm do trabalho e a aparência vem da ID escolhida — exceto o amarelo das falas do vídeo-fonte no react, que é regra deste formato. A receita é rascunho; a trilha é escolhida com o usuário.
