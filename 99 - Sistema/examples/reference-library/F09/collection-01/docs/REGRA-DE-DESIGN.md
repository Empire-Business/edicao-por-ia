# Regra de design da V5

1. O pacote **Premium v1** é o golden visual.
2. O PRD v5.2 e o pacote mestre são a fonte funcional.
3. As telas novas expandem o mesmo shell, hierarquia, contraste, roxo OMNX, cards, densidade e acabamento.
4. Não transformar estado/aba/drawer em página só para aumentar o número de imagens.
5. Conversas preserva sua composição e elementos protegidos.
6. Mobile é uma composição própria, não um desktop espremido.
