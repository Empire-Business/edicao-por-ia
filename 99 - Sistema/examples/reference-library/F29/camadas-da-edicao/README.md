# F29 — Camadas da Edição

Formato criado pelo autor em 28/11/2026 a partir de um criativo real do lote do Cortez (E127 V1), publicado como modelo a pedido dele. O próprio vídeo se desmonta em camadas 3D (cenas, animação, legenda, voz, trilha) enquanto a narração conta como ele foi feito; no fim, as camadas viram o vídeo pronto.

`reference.mp4` é uma cópia leve da prévia; o original fica na instalação do autor. As imagens são quadros reais desse vídeo e as provas mostradas são vídeos do próprio autor editados pelo Cortez.

Pessoas, nomes, assunto, provas, cores e fontes do exemplo não são padrões: a aparência vem da ID escolhida. O código-base da composição está em `motion/templates/camadas-da-edicao`. A receita é rascunho e ainda não foi testada numa edição de outro tema.
