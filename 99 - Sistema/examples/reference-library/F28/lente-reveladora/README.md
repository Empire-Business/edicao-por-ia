# F28 — Lente Reveladora

Formato criado pelo autor em 28/11/2026 a partir de um criativo real do lote do Cortez (E125 V2), publicado como modelo a pedido dele. Um feed genérico e cinza rola em 3D; uma lente de vidro passa por cima e, dentro dela, aparece o conteúdo real e caprichado — o contraste vende a qualidade.

`reference.mp4` é uma cópia leve da prévia; o original fica na instalação do autor. As imagens são quadros reais desse vídeo e as provas mostradas são vídeos do próprio autor editados pelo Cortez.

Pessoas, nomes, assunto, provas, cores e fontes do exemplo não são padrões: a aparência vem da ID escolhida. O código-base da composição está em `motion/templates/lente-reveladora`. A receita é rascunho e ainda não foi testada numa edição de outro tema.
