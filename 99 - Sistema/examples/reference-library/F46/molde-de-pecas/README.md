# F46 — Molde de Peças

Formato criado pelo autor em 28/11/2026 a partir de um criativo real do lote do Cortez (E142 V1), publicado como modelo a pedido dele. Um molde 9:16 com vagas vazias (voz, capa, legenda, cena, música, animação) é preenchido peça por peça no ritmo da narração até virar o vídeo pronto.

`reference.mp4` é uma cópia leve da prévia; o original fica na instalação do autor. As imagens são quadros reais desse vídeo e as provas mostradas são vídeos do próprio autor editados pelo Cortez.

Pessoas, nomes, assunto, provas, cores e fontes do exemplo não são padrões: a aparência vem da ID escolhida. O código-base da composição está em `motion/templates/molde-de-pecas`. A receita é rascunho e ainda não foi testada numa edição de outro tema.
