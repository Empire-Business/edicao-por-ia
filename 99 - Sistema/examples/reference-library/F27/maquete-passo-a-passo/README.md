# F27 — Maquete Passo a Passo

Formato criado pelo autor em 28/11/2026 a partir de um criativo real do lote do Cortez (E124 V2), publicado como modelo a pedido dele. Um processo explicado como maquete 3D clara vista de cima: cada passo da fala monta uma peça (arquivo, computador, pastas) até o resultado sair pronto.

`reference.mp4` é uma cópia leve da prévia; o original fica na instalação do autor. As imagens são quadros reais desse vídeo e as provas mostradas são vídeos do próprio autor editados pelo Cortez.

Pessoas, nomes, assunto, provas, cores e fontes do exemplo não são padrões: a aparência vem da ID escolhida. O código-base da composição está em `motion/templates/maquete-passo-a-passo`. A receita é rascunho e ainda não foi testada numa edição de outro tema.
