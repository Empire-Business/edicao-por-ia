# F44 — Cordilheira de Cortes

Formato criado pelo autor em 28/11/2026 a partir de um criativo real do lote do Cortez (E140 V1), publicado como modelo a pedido dele. Um vídeo longo vira uma cordilheira 3D desenhada pelo próprio áudio; os picos são os melhores trechos e cada um se levanta como um corte vertical pronto.

`reference.mp4` é uma cópia leve da prévia; o original fica na instalação do autor. As imagens são quadros reais desse vídeo e as provas mostradas são vídeos do próprio autor editados pelo Cortez.

Pessoas, nomes, assunto, provas, cores e fontes do exemplo não são padrões: a aparência vem da ID escolhida. O código-base da composição está em `motion/templates/cordilheira-de-cortes`. A receita é rascunho e ainda não foi testada numa edição de outro tema.
