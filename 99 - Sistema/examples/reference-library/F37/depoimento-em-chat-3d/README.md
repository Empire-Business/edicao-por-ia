# F37 — Depoimento em Chat 3D

Formato criado pelo autor em 28/11/2026 a partir de um criativo real do lote do Cortez (E120 V2), publicado como modelo a pedido dele. O áudio real de um cliente vira conversa num celular de vidro em 3D: bolhas de áudio com onda viva, placar de palhetas para números e um mergulho pela tela até as provas.

`reference.mp4` é uma cópia leve da prévia; o original fica na instalação do autor. As imagens são quadros reais desse vídeo e as provas mostradas são vídeos do próprio autor editados pelo Cortez.

Pessoas, nomes, assunto, provas, cores e fontes do exemplo não são padrões: a aparência vem da ID escolhida. O código-base da composição está em `motion/templates/depoimento-em-chat-3d`. A receita é rascunho e ainda não foi testada numa edição de outro tema.
