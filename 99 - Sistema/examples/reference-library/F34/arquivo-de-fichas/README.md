# F34 — Arquivo de Fichas

Formato criado pelo autor em 28/11/2026 a partir de um criativo real do lote do Cortez (E133 V1), publicado como modelo a pedido dele. Um arquivo de fichas em 3D: cada opção citada é uma gaveta etiquetada que abre e entrega a ficha com o exemplo real; as cores mudam num leque de amostras.

`reference.mp4` é uma cópia leve da prévia; o original fica na instalação do autor. As imagens são quadros reais desse vídeo e as provas mostradas são vídeos do próprio autor editados pelo Cortez.

Pessoas, nomes, assunto, provas, cores e fontes do exemplo não são padrões: a aparência vem da ID escolhida. O código-base da composição está em `motion/templates/arquivo-de-fichas`. A receita é rascunho e ainda não foi testada numa edição de outro tema.
