# F24 — Vitrine em Cilindro

Formato criado pelo autor em 28/11/2026 a partir de um criativo real do lote do Cortez (E121 V1), publicado como modelo a pedido dele. Quando a fala lista opções (tipos, modelos, variações), a câmera fica dentro de um cilindro de telas e cada opção citada gira para a frente com seu exemplo real.

`reference.mp4` é uma cópia leve da prévia; o original fica na instalação do autor. As imagens são quadros reais desse vídeo e as provas mostradas são vídeos do próprio autor editados pelo Cortez.

Pessoas, nomes, assunto, provas, cores e fontes do exemplo não são padrões: a aparência vem da ID escolhida. O código-base da composição está em `motion/templates/vitrine-em-cilindro`. A receita é rascunho e ainda não foi testada numa edição de outro tema.
