# F35 — Blocos de Tempo

Formato criado pelo autor em 28/11/2026 a partir de um criativo real do lote do Cortez (E134 V1), publicado como modelo a pedido dele. O tempo vira objeto: blocos maciços de dias caem pesados sobre uma régua de horas e se comprimem no tempo novo, com a prova real e o número final em 3D.

`reference.mp4` é uma cópia leve da prévia; o original fica na instalação do autor. As imagens são quadros reais desse vídeo e as provas mostradas são vídeos do próprio autor editados pelo Cortez.

Pessoas, nomes, assunto, provas, cores e fontes do exemplo não são padrões: a aparência vem da ID escolhida. O código-base da composição está em `motion/templates/blocos-de-tempo`. A receita é rascunho e ainda não foi testada numa edição de outro tema.
