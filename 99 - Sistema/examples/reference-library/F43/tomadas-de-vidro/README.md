# F43 — Tomadas de Vidro

Formato criado pelo autor em 28/11/2026 a partir de um criativo real do lote do Cortez (E139 V1), publicado como modelo a pedido dele. As tomadas reais de uma gravação viram lâminas de vidro em 3D; as que travam, gaguejam ou repetem saem uma a uma e só a melhor versão fica, nítida.

`reference.mp4` é uma cópia leve da prévia; o original fica na instalação do autor. As imagens são quadros reais desse vídeo e as provas mostradas são vídeos do próprio autor editados pelo Cortez.

Pessoas, nomes, assunto, provas, cores e fontes do exemplo não são padrões: a aparência vem da ID escolhida. O código-base da composição está em `motion/templates/tomadas-de-vidro`. A receita é rascunho e ainda não foi testada numa edição de outro tema.
