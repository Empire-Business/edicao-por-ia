# F25 — Antes e Depois em Fita

Formato criado pelo autor em 28/11/2026 a partir de um criativo real do lote do Cortez (E122 V2), publicado como modelo a pedido dele. A gravação bruta vira uma fita 3D com os trechos reais de fala, silêncio e erro; enquanto alguém explica a edição, os erros e pausas saem e a fita vira o vídeo pronto.

`reference.mp4` é uma cópia leve da prévia; o original fica na instalação do autor. As imagens são quadros reais desse vídeo e as provas mostradas são vídeos do próprio autor editados pelo Cortez.

Pessoas, nomes, assunto, provas, cores e fontes do exemplo não são padrões: a aparência vem da ID escolhida. O código-base da composição está em `motion/templates/antes-e-depois-em-fita`. A receita é rascunho e ainda não foi testada numa edição de outro tema.
