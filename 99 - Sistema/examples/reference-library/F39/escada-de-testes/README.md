# F39 — Escada de Testes

Formato criado pelo autor em 28/11/2026 a partir de um criativo real do lote do Cortez (E131 V2), publicado como modelo a pedido dele. Uma jornada de testes contada numa escada de vidro no céu: cada teste é um degrau maior com o resultado real, até o último virar vários vídeos prontos.

`reference.mp4` é uma cópia leve da prévia; o original fica na instalação do autor. As imagens são quadros reais desse vídeo e as provas mostradas são vídeos do próprio autor editados pelo Cortez.

Pessoas, nomes, assunto, provas, cores e fontes do exemplo não são padrões: a aparência vem da ID escolhida. O código-base da composição está em `motion/templates/escada-de-testes`. A receita é rascunho e ainda não foi testada numa edição de outro tema.
