# F41 — Gavetas de Pesquisa

Formato criado pelo autor em 28/11/2026 a partir de um criativo real do lote do Cortez (E137 V2), publicado como modelo a pedido dele. Uma parede escura de gavetas de arquivo: cada gaveta puxa material pesquisado de verdade (notícias, prints, cenas) enquanto o genérico de banco de imagens é carimbado e devolvido.

`reference.mp4` é uma cópia leve da prévia; o original fica na instalação do autor. As imagens são quadros reais desse vídeo e as provas mostradas são vídeos do próprio autor editados pelo Cortez.

Pessoas, nomes, assunto, provas, cores e fontes do exemplo não são padrões: a aparência vem da ID escolhida. O código-base da composição está em `motion/templates/gavetas-de-pesquisa`. A receita é rascunho e ainda não foi testada numa edição de outro tema.
