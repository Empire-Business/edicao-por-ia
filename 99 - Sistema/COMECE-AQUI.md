# Comece pela pasta visível

Escolha um formato F e uma ID visual ID. Exemplo: “Edite este vídeo com F01 e ID03”.
Os formatos definem a edição; as IDs definem cores e fontes. O trabalho recebe um código E e versões V.

Em 04 - Formatos, cada pasta numerada tem um guia HTML detalhado. Em 05 - IDs Visuais, escolha a aparência.
Novo formato precisa de nome simples e link de exemplo. Não usar um cliente/brand antigo como identidade automática.

Para preparar: peça na conversa. Para atualizar: “Atualize esta fábrica”. A main é aplicada ao código com backup, sem substituir seus trabalhos, memórias, IDs, chaves ou configurações locais.
