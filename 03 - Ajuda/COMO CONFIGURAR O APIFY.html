Configurar o Apify

Faça um passo de cada vez. Se travar em algum, conte ao Cortez o que aparece na tela e ele explica o próximo.

O que é e para que serve

O Apify é opcional. O Cortez só usa quando o ScrapeCreators encontra um vídeo do YouTube mas não entrega o arquivo para baixar. Aí o Apify baixa esse vídeo.

Se você não configurar, nada quebra: o Cortez pede para você enviar o vídeo ou escolhe outra cena.

Quanto custa

O plano grátis dá US$ 5 de uso por mês, sem cartão. Para o Cortez, costuma bastar. Quando os US$ 5 acabam, o Apify para de funcionar até o mês seguinte, sem cobrar nada a mais. O que sobra no mês não acumula.

Planos pagos existem (veja em apify.com/pricing), mas não são necessários para começar.

Passo 1: criar a conta

  1. Abra console.apify.com.
  2. Clique para criar a conta (sign up) e entre com e-mail ou com a opção de login que aparecer.
  3. Fique no plano Free (grátis).

Passo 2: copiar a chave (token)

O token é uma senha que deixa o Cortez usar a sua conta do Apify.

  1. Abra console.apify.com/settings/integrations (a página API & Integrations).
  2. Em Personal API tokens, copie o token que já existe ou crie um novo com o nome Cortez.

Passo 3: colar no arquivo de chaves

  1. Na pasta do Cortez, abra o arquivo CHAVES DAS INTEGRAÇÕES.txt (dois cliques).
  2. Ache a linha APIFY_API_TOKEN=. Se ela não existir, escreva essa linha no fim do arquivo.
  3. Cole o token logo depois do sinal =, sem espaço e sem aspas.
  4. Salve o arquivo e feche.

Nunca cole o token na conversa com a IA. Se colou por engano, apague esse token na mesma página do Apify e crie outro. Também não envie o arquivo de chaves para ninguém.

Passo 4: conferir

Não precisa testar agora. Da próxima vez que o Cortez precisar baixar um vídeo do YouTube, ele avisa que vai usar o Apify e conta se deu certo.

Se aparecer um aviso

  • Token recusado: copiado pela metade ou apagado. Crie outro e cole.
  • Limite do mês atingido: os US$ 5 grátis acabaram. Espere o mês virar ou envie o vídeo você mesmo.
