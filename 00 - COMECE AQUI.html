Editar seus vídeos

Escolha o jeito de editar e a aparência separadamente.

1. Escolha o formato

F01, F02… definem cortes, ritmo, cenas e animações.

Ver formatos e guias da edição

2. Escolha a ID visual

ID01, ID02… definem cores e fontes. Qualquer formato pode usar qualquer ID visual.

Ver IDs visuais

3. Envie os materiais

Coloque gravações, roteiro e apoios em 01 - Enviar vídeos. Peça na conversa: “Edite este vídeo com F01 e ID03.”

A fábrica cria uma edição E01, E02… Para ajustar, diga: “Na E01, aos 12 segundos, tire o texto”. As versões V1, V2… ficam em 02 - Ver vídeos.

Logotipos só entram quando forem pedidos para aquele vídeo.

Cadastrar um novo formato

Envie um nome simples e um link de exemplo: Instagram, Drive, X ou outro site. A fábrica cria o próximo código F. Os formatos antigos podem permanecer sem esse link.

Atualizar sem perder seus trabalhos

Peça: “Atualize esta fábrica.” A versão da main do GitHub é conferida e aplicada com backup, mantendo trabalhos, memória, IDs visuais e configurações locais.

Se houver conflito com uma personalização de código, sua versão fica intacta para revisão. Não é preciso trocar a pasta inteira.

Chaves das integrações

Abra CHAVES DAS INTEGRAÇÕES.txt, cole as chaves depois do sinal = e salve. Esse arquivo é privado.
