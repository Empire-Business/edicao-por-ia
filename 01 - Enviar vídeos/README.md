# Enviar vídeos

Coloque aqui as gravações que quer editar. Você pode criar uma pasta com o nome
da edição e colocar o roteiro e as imagens junto. Depois, diga ao Claude o nome
do arquivo e o que quer mudar. Colocar um arquivo aqui não inicia uma edição.
As gravações permanecem como você enviou; a edição gera novos arquivos.
